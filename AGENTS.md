# 5GOR — такси в Пятигорске

Драйв-симулятор такси в Пятигорске: заказы, пассажиры, трафик по ПДД,
светофоры, пешеходы, ночной режим. Веб-игра на Three.js, без ассетов — вся
графика генерируется кодом. `src/*` собирается скриптом `build.py` в
самодостоятельный `index.html`.

> **Общие правила для ИИ-агентов — глобальные:** `~/.hermes/agents/rules.md`.
> Здесь — только специфика этого проекта. Каскад: глобальные правила → этот файл
> → конкретная инструкция вызова.

## Правила

### Сборка index.html
`index.html` — сгенерированный артефакт, коммитится в git. После правки любого
файла в `src/` нужно пересобрать через `python3 build.py`.
[Подробности](.agents/rules/build-workflow.md)

### Ограничения сборщика
`build.py` — регулярки, а не транспилятор: однострочные import/export, общий
global scope для всех модулей после сборки, порядок в `MODULES` — это порядок
зависимостей.
[Подробности](.agents/rules/bundler-constraints.md)

### Тесты
`node:test`, запуск строго с явным путём: `node --test tests/*.test.mjs`.
[Подробности](.agents/rules/testing.md)
