# Дизайн: интерактивная карта репозитория (repo-map.html)

Дата: 2026-08-09

## Цель

Интерактивная карта текущего репозитория в виде отдельного self-contained HTML-файла:
история коммитов с просмотром diff'ов + карта файлов/модулей. Открывается двойным
кликом в браузере, без сервера и внешних зависимостей.

## Подход

- Генерация: Python-скрипт `repo-map.py` в корне (в стиле существующего `build.py`).
- Выход: `repo-map.html` — self-contained (встроенные CSS, JS, данные).
- Данные фиксируются на момент генерации; для обновления нужно перезапустить скрипт.
- Запуск: `python3 repo-map.py`.

## Данные (JSON, встраиваются в HTML)

- Коммиты (все): hash, автор, дата, сообщение, статистика +N/−M.
- Diff каждого коммита по файлам: строки с пометкой `+` / `-` / контекст.
- Дерево отслеживаемых файлов на текущем HEAD: метрики активности
  (кол-во коммитов, тронувших файл; суммарно строк добавлено/удалено).

## Исключения (артефакты)

Из истории и diff'ов исключаются сгенерированные артефакты, раздувающие карту:

- `index.html` (575KB, пересобирается каждый коммит)
- `*.log`, `*.pid` (например `.server.log`, `.server.pid`)
- `.git/` само собой не трекается git-ом

Код, тесты, доки показываются полностью.

## Обработка граничных случаев

- Пустой diff → секция «нет изменений в файлах» или скрытие пустых секций.
- Бинарные файлы → пометка `binary`, содержимое не показывается.
- Переименованные файлы → отображаются как rename (без дублирования diff'а),
  если git отдаёт rename.

## Интерфейс — три панели

**Слева — вкладки:**
- «Файлы»: сворачиваемое дерево файлов; у каждого файла счётчик коммитов и +N/−M.
  Клик по файлу → список коммитов, менявших файл, и diff по файлу.
- «Коммиты»: хронологический список, сгруппированный по датам; каждый коммит —
  hash, сообщение, стата +N/−M. Клик → полный diff коммита.

**Справа — просмотр diff:**
- Секции по файлам, сворачиваются/разворачиваются.
- Добавления зелёным, удаления красным, контекст нейтральным.
- Лёгкая подсветка: подсветка знаков `+`/`-` в начале строки.

**Поиск:**
- Фильтр коммитов по сообщению/хэшу.
- Фильтр файлов по имени (в дереве и в diff'ах).

## Критерии приёмки

- `python3 repo-map.py` создаёт `repo-map.html` без ошибок.
- Файл открывается локально (`open repo-map.html`), интерфейс отображается.
- Клик по коммиту показывает diff; клик по файлу показывает его историю.
- Артефакты (index.html и др.) отсутствуют в истории и дереве.
- JSON внутри HTML валиден (генерируется через `json.dumps`).

## Вне рамок

- Живое обновление через локальный сервер (по запросу — отдельная итерация).
- Загрузка больших репозиториев (>1000 коммитов): пока не требуется, но
  генерация должна быть быстрой и без записей данных в сеть.
- Ветки/граф слияний: в репо одна ветка main, граф не рисуем.
