# 5GOR — такси в Пятигорске

Драйв-симулятор такси в Пятигорске: заказы, пассажиры, трафик по ПДД,
светофоры, пешеходы, ночной режим. Веб-игра на Three.js, без ассетов —
вся графика генерируется кодом.

## Сборка

```
python3 build.py
```

Скрипт собирает `src/` в один самодостаточный `index.html` (three.js
подключается из CDN).

## Запуск

Открыть `index.html` в браузере или раздать статикой, например:

```
python3 -m http.server 8077
```

## Управление

- **WASD / стрелки** — газ, тормоз, руль
- **E** — взаимодействие (взять заказ, высадить пассажира)
- **H** — клаксон, **L** — фары, **M** — карта
- На мобильных — виртуальный джойстик

## Структура

- `src/config.js` — конфигурация мира и машины
- `src/citygen.js` — генерация города (дороги, здания, светофоры, точки посадки)
- `src/player.js` — машина игрока
- `src/traffic.js` — трафик (ПДД, светофоры, повороты)
- `src/peds.js` — пешеходы
- `src/orders.js` — заказы и пассажиры
- `src/ui.js` — HUD, миникарта, навигатор
- `build.py` — сборка в один файл
