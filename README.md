# 5GOR — такси в Пятигорске

Драйв-симулятор такси в Пятигорске: заказы, пассажиры, трафик по ПДД,
светофоры, пешеходы, ночной режим. Веб-игра на Three.js, без ассетов —
вся графика генерируется кодом.

## Сборка

```bash
python3 build.py
```

Скрипт собирает `src/` в один самодостаточный `index.html` (three.js
подключается из CDN). `index.html` — сгенерированный артефакт, коммитится.

## Запуск

Открыть `index.html` в браузере или раздать статикой, например:

```bash
python3 -m http.server 8077
```

## Тесты

```bash
node --test tests/*.test.mjs
```

## Управление

- **WASD / стрелки** — газ, тормоз, руль
- **E** — взаимодействие (взять заказ, высадить пассажира)
- **H** — клаксон, **L** — фары, **M** — карта
- На мобильных — виртуальный джойстик

## Структура

- `src/config.js` — конфигурация мира, машин, апгрейдов, районов
- `src/citygen.js` — генерация города (дороги, здания, светофоры, точки посадки)
- `src/player.js` — машина игрока (физика, коллизии, топливо)
- `src/traffic.js` — трафик (ПДД, светофоры, повороты)
- `src/peds.js` — пешеходы и животные
- `src/orders.js` — заказы и пассажиры
- `src/police.js` — штрафы за нарушения ПДД
- `src/achievements.js` — достижения
- `src/ui.js` — HUD, миникарта, навигатор, гараж
- `src/audio.js` — звук (движок, эффекты, музыка)
- `src/carmodel.js` — процедурные модели машин
- `src/pedgraph.js`, `src/pedavoid.js` — маршруты и обход препятствий пешеходами
- `src/game.js` — главный цикл, состояния, сохранения
- `build.py` — сборка в один файл

## Для разработчиков

- `AGENTS.md` — правила для ИИ-агентов (сборка, тесты, коммиты)
- `.agents/architecture.md` — архитектура, кодстайл, паттерны и ловушки
- `.agents/rules/` — детальные правила (сборка, бандлер, тесты, коммиты)
